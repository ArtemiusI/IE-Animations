Low quality steps to paletted sprites:

1. Import models to Blender (I used NWN models with Beamdog HD pack)
2. Edit textures using GIMP, changing colors according to IE palette designations: e.g.
   - To designate major color, select the desired textures and adjust the Color Balance of shadows, midtones and highlights, changing the magenta level all the way to the maximum
   - Do the same with other colors:
   - Minor color: cyan
   - Skin color: yellow
   - Leather color: red
   - Hair color: green
   - Armor color: blue
   - Metal color: grey
3. Render animations
4. Import frames into GIMP as layers.
5. Convert the layers to indexed with Image -> Mode -> Indexed... Set Colourmap -> Use custom palette -> sprites.pal
6. Convert the layers back to RGB with Image -> Mode - > RGB
7. Now convert the layers to indexed again but this time, Use custom palette -> bgpalette.pal.
8. Export layers.
9. Convert images to BAM.
